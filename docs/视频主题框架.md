*   **目标：** 构建专业、系统且易读的金融交易知识库。

## 三、 视频制作规范（SOP）
*   **时长控制：** 150s - 180s。
*   **结构：** 痛点钩子(15%) -> 核心逻辑(40%) -> 实战避坑(35%) -> 总结升华(10%)。
*   **视觉风格：** 建议使用TradingView动态图表录制 + 极简Keynote动效。
*   **音频：** 语速建议220-250字/分钟，配乐需根据主题切换（逻辑类用Lo-fi，传奇类用Epic）。

## 四、 样片脚本示例

**主题：** 10大经典交易策略
**第一集：** 《双均线策略：趋势跟踪的鼻祖》

| 时间段 | 画面内容 | 配音/文案 |
| :--- | :--- | :--- |
| **00-25s (钩子)** | 快速切换红绿交替的K线，心跳声背景音。 | 为什么你总是买在最高点，卖在最低点？明明看对了方向，却在震荡中被洗出门外？其实，交易不需要复杂的算法。今天，我们要聊的是所有职业交易员的必修课——**双均线策略**。 |
| **25-85s (原理)** | 白底K线图，缓缓画出金黄色快线和蓝色慢线。 | 所谓双均线，就是用两条不同周期的移动平均线，过滤市场噪音。比如最经典的20日和60日组合。快线代表短期情绪，慢线代表长期趋势。当快线向上穿过慢线，这就是**“金叉”**，多头觉醒，入场！反之，向下穿过则是**“死叉”**，趋势反转，离场！ |
| **85-155s (实战)** | 展示一个单边趋势大赚的图表，紧接着展示一个震荡行情反复被打脸的图表。 | 听起来简单？但80%的人都栽在八个字：**“趋势盈利，震荡还债”**。双均线在单边行情中是收割机，但在横盘震荡里就是绞肉机。**进阶技巧：** 观察成交量。如果金叉伴随成交量放大，信号才可靠。记住，均线是用来追踪趋势的，不是用来预测震荡的。 |
| **155-180s (结尾)** | 画面定格，打出字幕：“交易不是预测未来，而是对现状的反应。” | 双均线的核心不是精准预测，而是**“顺势而为”**。它牺牲了捕捉最高点的可能，换取了确认趋势后的安全感。下期视频，我们聊聊波动率的艺术——**布林带策略**。点赞关注，建立你的交易系统。 |
